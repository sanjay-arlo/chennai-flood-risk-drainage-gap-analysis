# Chennai Flood-Risk & Stormwater Drainage Gap Analysis

> Business Analyst portfolio case study analysing ward-level flood exposure, stormwater-drain completion and monsoon-preparedness priorities.

## 🚀 Live Dashboard

**[Open the interactive dashboard](https://sanjay-arlo.github.io/chennai-flood-risk-drainage-gap-analysis/)**

## Business question

**Which wards carry the highest flood risk relative to drainage completion, and where should monsoon-prep budget go first?**

## What the dashboard shows

- Flood-incident exposure by ward
- Claimed drainage completion
- Elevation/flood-watch risk
- Risk-priority ranking
- Monsoon budget allocation signal
- Interactive ward and zone filtering

## Decision flow

Ward data → quality checks → risk KPIs → priority ranking → intervention recommendation

## Dataset

The dashboard uses a **synthetic illustrative dataset embedded in the client-side application** for portfolio demonstration. It is not official Greater Chennai Corporation operational data.

## KPI logic

**Completion gap** = Claimed completion % − resident-reported completion %

**Risk priority** combines incident exposure, elevation risk and incomplete drainage coverage.

## Business Analyst deliverables

Stakeholder framing, requirements thinking, KPI definition, prioritisation logic, dashboard design and production-upgrade recommendations are demonstrated in the dashboard itself.

## Production upgrade

Replace the illustrative layer with governed ward drainage records, verified rainfall gauges, flood incident data, elevation models, capex records and a master ward geography. Add refresh SLAs, data-quality monitoring and approval thresholds before operational use.

## Limitation

This is a **portfolio case study**, not an official flood-risk audit or emergency-management system.
